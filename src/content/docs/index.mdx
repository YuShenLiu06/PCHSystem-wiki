## 核心功能

<CardGrid>
	<Card title="项目协作" icon="rocket" href="/PCHSystem-wiki/gameplay/project-lifecycle/">
		认领材料、多人累计上交、交付确认、打回返工——Web 端与游戏端对等操作。
	</Card>
	<Card title="施工统计" icon="analytics" href="/PCHSystem-wiki/gameplay/construction/">
		自动追踪每位参与者的方块放置贡献,多种图表直观展示项目进度。
	</Card>
	<Card title="积分体系" icon="database" href="/PCHSystem-wiki/gameplay/scoring/">
		项目完结后按贡献占比自动结算积分,统一积分入账与排行榜。
	</Card>
	<Card title="称号系统" icon="star" href="/PCHSystem-wiki/gameplay/titles/">
		积分达标自动解锁称号,聊天前缀差异化,高阶全服公告。
	</Card>
	<Card title="一键建表" icon="add-document" href="/PCHSystem-wiki/guide/submit-materials/">
		上传投影 / 蓝图,自动解析方块、翻译中文名、生成材料清单。
	</Card>
	<Card title="消息通知" icon="comment-alt" href="/PCHSystem-wiki/guide/web-dashboard/">
		认领、交付、打回等事件游戏内自动通知,离线通知上线补推。
	</Card>
</CardGrid>
