## 基础命令

| 命令 | 说明 |
|------|------|
| `!!PCH` | 显示帮助菜单 |
| `!!PCH login` | 获取 Web 后台登录链接 |
| `!!PCH bind` | 发起账号绑定（获取短码） |
| `!!PCH bind <code>` | 消费 Web 端短码完成绑定 |
| `!!PCH status` | 前后端连接自检 |
| `!!PCH info` | 个人信息：UUID / 绑定状态 / 称号 |

## 项目命令

| 命令 | 说明 |
|------|------|
| `!!PCH project list` | 项目列表 |
| `!!PCH project info <项目>` | 查看项目详情 |

## 表格快速入口

| 命令 | 说明 |
|------|------|
| `!!sheet` | 重开上次查看的表格 |
| `!!sheet <编号>` | 打开指定表格 |
| `!!submit` | 重开上次表格并直接提交 |
| `!!submit <编号>` | 指定表格提交 |

## 积分与称号

| 命令 | 说明 |
|------|------|
| `!!PCH score` | 查看个人积分 |
| `!!PCH rank [分类]` | 查看排行榜 |
| `!!PCH title list` | 已解锁称号列表 |
| `!!PCH title set <称号>` | 切换展示称号 |

## 施工命令

| 命令 | 说明 |
|------|------|
| `!!PCH construction status` | 查看追踪器状态 |
| `!!PCH construction join [编号]` | 加入施工项目 |
| `!!PCH construction leave` | 退出施工 |
| `!!PCH construction current` | 查看当前施工项目 |

:::tip[提示]
游戏内大部分操作都支持 **点击交互** —— 聊天框中的按钮可以直接点击执行，尽量减少手动输入命令。
:::
