欢迎使用 PCHSystem！本页面将带你完成从加入服务器到提交贡献的全部流程。

<Steps>

1. **加入服务器**

   确保你已在白名单中（联系管理员申请），使用对应的客户端模组包连接服务器。进服后输入 `!!PCH` 查看所有可用命令。

2. **登录 Web 后台**

   输入 `!!PCH login`，点击聊天框中的链接即可直接进入 Web 后台，无需密码。新玩家会自动获得一个临时账号，可以直接使用，也可以稍后在个人中心注册转为永久账号。

3. **绑定已有账号（可选）**

   如果你**已有** Web 账号（例如换了游戏 ID，想把新身份关联到旧账号），使用 `!!PCH bind` 将当前游戏角色绑定到已有账号。

   :::note[login 和 bind 的区别]

   - `!!PCH login` — 首次进入 / 日常登录，自动创建临时账号或直接进入已绑定的账号。
   - `!!PCH bind` — **已有** Web 账号时，将一个**新的**游戏身份绑定到该账号。
      :::

   详见 [绑定账号](/PCHSystem-wiki/guide/bind-account/) 页面。

4. **浏览项目列表**

   游戏内输入 `!!PCH sheet list` 查看当前进行中的项目。加上 `-m` 只看自己参与的：`!!PCH sheet list -m`

5. **认领材料**

   找到你感兴趣的项目后，输入 `!!PCH sheet view <项目编号>` 查看材料清单。在游戏内点击材料行旁的 `[认领]` 按钮即可认领。

6. **提交材料**

   收集好材料后，将物品放入背包（可以嵌套潜影盒），然后输入 `!!PCH sheet submit <项目编号>` 或者使用 `!!submit <项目编号|可选>` 如果**不填写编号**则为最近打开的项目。系统会自动扫描背包然后提交。

   也可以手持物品建行：`!!PCH sheet addhand <项目编号> <数量>`（注意：这是从手持物品创建材料行，不是提交材料）

7. **查看你的贡献**

   再次输入 `!!PCH sheet view <项目编号>`，已交付的材料会标记为 ✓同时自动的排序到最后，你的贡献量一目了然。

8. **参与施工**

   如果你们服务器使用的默认的上报器，那么使用 [施工指令](/PCHSystem-wiki/commands/construction-commands/) 或者在web端项目右上角处点击加入施工即可

</Steps>
