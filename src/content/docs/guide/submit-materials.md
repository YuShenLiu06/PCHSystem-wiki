title: 认领与提交材料
description: 如何在项目中认领、上交和交付材料
---

## 材料清单概览

每个项目都有一张 **材料清单（Sheet）**，列出完成该项目所需的所有材料。清单支持两种行类型：

| 类型 | 说明 | 锁定方式 |
|------|------|----------|
| **锁定行（lock）** | 单人认领，认领后其他人不可再认 | 认领即锁定，交付后自动解锁 |
| **进度行（progress）** | 多人共同贡献，各自累计上交 | 不锁定，所有人可同时贡献 |

## 认领材料

### 游戏内认领

1. 查看材料清单：

   ```
   !!PCH sheet view <项目编号>
   ```

2. 点击材料行旁的 `[认领]` 按钮

3. 认领后该行会显示你的名字，其他人无法再认领

### Web 端认领

在 Web 后台打开项目，点击材料行的认领按钮即可。

## 提交材料

### 方式一：扫背包提交

将收集好的材料放入背包（支持嵌套潜影盒），执行：

```
!!PCH sheet submit <项目编号>
```

系统自动扫描整个背包（含潜影盒内物品），匹配清单中你认领的材料行，完成上交。

### 方式二：快捷别名

```
!!submit              # 重开上次查看的项目并提交
!!submit <项目编号>    # 指定项目提交
```

### 手持物品建行（≠提交）

如果你手持某种材料想直接在清单中创建一行，使用：

```
!!PCH sheet addhand <项目编号> <数量>
```

注意：`addhand` 是从手持物品**创建材料行**，不是提交材料。

## 其他操作

| 操作 | 命令 | 说明 |
|------|------|------|
| 解除认领 | `[解除]` 按钮 | 放弃已认领但未交付的行 |
| 打回返工 | `!!PCH sheet reject` | 项目负责人专用，打回有问题的交付 |
| 查看进度 | `!!PCH sheet view <编号>` | 查看清单和各材料状态 |
| 通知列表 | `!!PCH sheet notify list` | 查看待处理通知 |
