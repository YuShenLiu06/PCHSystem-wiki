title: 绑定账号
description: 将游戏账号与 Web 账号绑定
---

## 为什么需要绑定？

绑定后你可以：

- 在 **Web 端** 查看和编辑材料清单（不进游戏也能协作）
- 使用 **一键登录** — 游戏内 `!!PCH login` 直接打开 Web 后台
- 在 Web 端 **上传投影 / 蓝图** 自动建表
- 查看个人贡献统计和积分

## 绑定流程

### 方式一：从游戏内发起（推荐）

1. 游戏内输入：

   ```
   !!PCH bind
   ```

2. 系统会返回一个 **短码**（灰色文字）

3. 在 Web 后台登录页面输入该短码，完成绑定

4. 绑定完成

## 一键登录

绑定完成后，随时可以用以下命令获取登录链接：

```
!!PCH login
```

点击聊天框中的链接即可直接进入 Web 后台，无需输入密码。链接有时效限制，过期后重新获取即可。

## 常见问题

:::note[换了游戏ID怎么办？]
本服为离线模式，改名后 UUID 会变化。请使用绑定的 Web 账号重新执行绑定流程。
:::

:::caution[短码安全]
短码是敏感信息，请勿在公共频道发送。游戏内短码显示为灰色，不会高亮。
:::
