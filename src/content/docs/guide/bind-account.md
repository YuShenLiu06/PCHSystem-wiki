## login 和 bind 的区别

PCHSystem 有两个与账号相关的游戏内命令，用途不同：

| 命令 | 用途 | 适用场景 |
|------|------|---------|
| `!!PCH login` | **登录** Web 后台 | 首次使用、日常登录 |
| `!!PCH bind` | **绑定** 新游戏身份到已有 Web 账号 | 已有 Web 账号，换了游戏 ID 或新增角色 |

### 首次使用 → `!!PCH login`

新玩家不需要预先注册。游戏内输入 `!!PCH login`，点击聊天中的链接即可进入 Web 后台。系统会自动创建一个**临时账号**，你可以直接使用所有功能。

如果后续想要设置密码、长期使用，可以在个人中心将临时账号转为永久账号。

### 已有账号 + 新游戏身份 → `!!PCH bind`

`!!PCH bind` 用于把**当前游戏身份**绑定到你**已有的** Web 账号。常见场景：

- **新增角色** → 把多个游戏身份归到同一个 Web 账号下
- **换了游戏 ID** → 在以玩家名推导 UUID 的服务器（离线模式）上，改名后 UUID 会变化，相当于换了新身份

无论哪种情况，你的 **Web 账号**都是身份主锚——贡献记录跟随 Web 账号，不会因游戏 UUID 变化而丢失。

## 绑定流程

1. 游戏内输入：

   ```
   !!PCH bind
   ```

2. 系统会返回一个**短码**和可点击的链接

3. 点击链接（或在 Web 后台绑定页面输入短码），完成绑定

4. 绑定完成后，该游戏身份即关联到你的 Web 账号

绑定后随时可以用 `!!PCH login` 一键进入后台。

## 常见问题

:::note[换了游戏ID怎么办？]
若你的服务器以玩家名推导 UUID（离线模式），改名后 UUID 会变化，请用 `!!PCH bind` 把新 ID 重新绑定到 Web 账号。正版验证（online-mode）服务器的 UUID 不随改名变化，一般无需操作。
:::

:::caution[短码安全]
短码是敏感信息，请勿在公共频道发送。游戏内短码显示为灰色，不会高亮。
:::
