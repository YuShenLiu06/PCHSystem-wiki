## 概述

PCHSystem 提供独立的 Web 前端，你可以在浏览器中完成绝大多数操作，无需进游戏。

## 进入 Web 后台

### 方式一：一键登录（推荐）

游戏内输入：

```
!!PCH login
```

点击聊天中的链接，直接进入后台，无需密码。

### 方式二：账号登录

访问 Web 后台地址，使用已绑定的账号登录。

## 核心功能

### 📋 在线表格编辑

在 Web 端可以直接编辑材料行：

- 修改材料名称、数量、registry-id
- 认领、交付、解除锁定
- 添加 / 删除材料行

Web 端操作与游戏端 **完全对等**。

### 📦 投影 / 蓝图一键建表

**仅 Web 端支持** 的功能：

1. 上传 `.litematic` 投影文件（或机械动力 `.nbt` 蓝图）
2. 系统自动解析方块、翻译成中文名
3. 生成完整的材料清单
4. 支持多份投影文件合并为同一个项目
5. 支持单个投影设置倍数

### 📊 项目进度监控

- 查看项目进度图表
- 多种图表直观展示
- 实时更新

### 👥 项目管理（负责人）

项目负责人可在 Web 端：

- 修改材料清单
- 打回提交
- 流转项目阶段（材料收集 → 施工 → 归档）
- 管理协管员
- 查看贡献占比饼图

## 命令与 Web 端对照

| 操作 | 游戏内命令 | Web 端 |
|------|-----------|--------|
| 查看清单 | `!!PCH sheet view` | 项目详情页 |
| 认领材料 | `[认领]` 按钮 | 点击认领 |
| 提交材料 | `!!PCH sheet submit` | Web 端编辑 |
| 项目流转 | `!!PCH sheet advance` | 阶段按钮 |
| 上传投影 | ❌ | ✅ |
