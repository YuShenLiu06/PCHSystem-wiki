## 设计理念

积分体系的核心原则：**贡献即积分，全程自动化**。

- 项目完结后按贡献占比自动结算
- 积分流水 append-only（只增不改，可审计）
- 玩家间不可自由转移

## 物品收集类项目

按玩家交付占比分配固定积分池：

```
S_i = S_总 × (n_i / N_总)
```

| 变量 | 含义 |
|------|------|
| `S_总` | 项目固定总积分池 |
| `n_i` | 玩家个人材料交付量 |
| `N_总` | 全项目材料总交付量 |

**特点**：认可工厂自动化产出，无来源限制。前置交付有额外权重加成。

## 建造放置类项目

放置贡献 + 收集贡献加权计算：

```
G = α·(t/T) + β·(p/P)    （α + β = 1）
```

| 变量 | 含义 |
|------|------|
| `α` | 放置行为权重 |
| `β` | 收集行为权重 |
| `t/T` | 个人放置工作量占比 |
| `p/P` | 个人收集产出占比 |

最终积分 = 项目总积分池 × 个人贡献度占比 `G`。

## 项目负责人奖励

负责人额外获得全体积分总和的百分比奖励：

```
S_负责人 = S_全体总积分 × k    （k ∈ [0.05, 0.5]）
```

系数 `k` 按项目规模自动匹配，额外增发，不占用玩家基础积分池。

## 积分排行榜

| 榜单 | 说明 |
|------|------|
| 🏆 总榜 | 全服历史累计积分，核心荣誉墙 |
| 📅 赛季/月度榜 | 周期重置，给新人追赶空间 |
| 📦 单项目榜 | 归档后的项目名人堂 |
| 📊 分类榜 | 放置贡献 / 收集贡献分开设榜 |

## 积分流水

所有积分变动记录在 `score_ledger` 中：

- **Append-only**：禁止修改和删除
- 每条记录包含 `balance_after`（变动后余额）
- 可随时审计重建任意时间点的积分状态
