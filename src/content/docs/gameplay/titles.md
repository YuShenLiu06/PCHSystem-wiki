:::caution[开发中]
称号系统仍在开发中，以下为设计规则。
:::

## 核心机制

积分达标 → **自动解锁** 称号，无需手动申请。

升级所需积分呈指数增长：

```
S_升级 = S_基 × r^(等级-1)
```

| 变量 | 含义 |
|------|------|
| `S_基` | 等级基础积分值 |
| `r` | 固定增长系数 |
| `等级` | 当前称号等级 |

**特点**：前期容易获取，后期门槛指数级提升。

## 称号展示

- **聊天前缀**：称号显示在玩家名前，不同等级视觉差异化
- **自由切换**：解锁多个称号后可自由选择展示哪一个
- **全服公告**：高阶称号解锁时触发全服公告

## 管理命令

| 命令 | 说明 |
|------|------|
| `!!PCH title list` | 查看已解锁的称号 |
| `!!PCH title set <称号>` | 切换展示的称号 |

## 社区权益

高阶称号解锁后可能获得的身份权益：

- Wiki 专属用户组
- 社区展示权益（如纪念墙署名等，视服务器配置而定）
